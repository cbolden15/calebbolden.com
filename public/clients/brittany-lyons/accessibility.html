Home/Accessibility

Accessibility statement.

A home should feel like it belongs to everyone in it. This website should work the same way.

Our standard

We aim for this website to meet WCAG 2.2 Level AA, the widely used benchmark for web accessibility. That includes things like readable color contrast, keyboard navigation, image descriptions for screen readers, and clear page structure.

Ongoing work

Accessibility isn't a box we check once. As pages are added or redesigned, we review them against these standards, and we treat any gap we find as something to fix rather than something to note and move past.

If something doesn't work for you

If you run into a barrier anywhere on this site, whether that's a page that doesn't work with a screen reader, text that's hard to read, or something you can't reach by keyboard, please tell us. Email info@brittanylyonsinteriors.com with the page and a description of the issue, and we'll look into it.
