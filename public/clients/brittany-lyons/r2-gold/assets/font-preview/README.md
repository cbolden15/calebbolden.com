# Gilded Light font preview

The Fonts control offers 20 heading and paragraph pairings. Pair 01, Lora + DM Sans, is the default. A selection changes this browser only, persists between pages, and can be reset in the panel.

Font files are self-hosted WOFF2 subsets from Google Fonts. All families include real regular and italic faces, with weights from 400 through 700 (variable ranges where available). Only fonts used by the active page or selected pairing are requested by the browser. The control itself always uses DM Sans.

Each family has its SIL Open Font License alongside the font files. `sources.json` records the original family metadata, download URLs, file hashes, and licenses. CSS family aliases start with `BLI Preview` to keep the review tool separate from earlier design variants. Downloads use the [Google Fonts CSS2 API](https://developers.google.com/fonts/docs/css2).
