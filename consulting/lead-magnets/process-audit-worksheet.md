# The one-hour process audit

*Map one workflow, find the waste, and know what to fix first. One hour, one process, pen and paper. For owners of businesses with 2 to 50 people.*

---

Most software projects fail for people and process reasons, not technical ones. Analysts who study failed CRM rollouts put over 60% of the blame on adoption and process problems, and under 10% on the platform itself. The fix is boring and it works: understand the process before you buy anything for it.

This worksheet walks you through the same first hour I spend with consulting clients. You do not need me for it. Do it honestly and you will know more about your own business by lunch.

## Step 1: pick your process (5 minutes)

Pick ONE workflow. Not your whole business. Good candidates: the one that generates the most complaints, the one only you know how to do, or the one that touches money (quotes, invoices, collections).

- Process name: ________________________________
- How often it runs (per week): ______
- Why it hurts (one sentence): ________________________________
- What triggers it (a call? a form? a sale?): ________________________________
- What "done" looks like: ________________________________

## Step 2: walk the steps (15 minutes)

List every step from trigger to done, left to right or top to bottom. Aim for 4 to 10 steps; if you have more than 10, you are listing sub-steps, zoom out. For each step write three things:

| Step | Who does it | What tool or system | How long it WAITS before someone picks it up |
|------|-------------|--------------------|-----------------------------------------------|
| 1. | | | |
| 2. | | | |
| 3. | | | |
| 4. | | | |
| 5. | | | |
| 6. | | | |
| 7. | | | |
| 8. | | | |

The last column matters most. In most office processes the work itself is fast; the waiting between steps is where days disappear.

Now mark the map:

- **Circle** every step where the same information gets typed again into a different system.
- **Star** the single longest wait.

## Step 3: the waste checklist (15 minutes)

Go through these eight questions about the process you just mapped. Check every yes.

- [ ] **Redoing:** Do you regularly fix data-entry mistakes or redo paperwork in this process?
- [ ] **Too early:** Does anything get prepared, printed, or processed before it is actually needed?
- [ ] **Waiting:** Does work sit in an inbox or queue waiting on an approval or a reply?
- [ ] **Wasted skill:** Does your most skilled person spend time here on something anyone could do?
- [ ] **Hand-offs:** Does information pass through people or systems it does not need to?
- [ ] **Backlog:** Is there a pile of unprocessed files, unread messages, or unbilled work in this process?
- [ ] **Re-entry:** Do people re-type the same data, bounce between apps, or hunt for information?
- [ ] **Rubber stamps:** Are there approvals or checks in this process that never actually change anything?

Count your checks: ______ / 8

Three or more checks on one process is normal and fixable. The checks tell you what kind of fix you need: waiting and hand-off problems are usually process fixes (free), re-entry and backlog problems are usually automation fixes (cheap), wasted-skill problems are usually delegation fixes (a decision).

## Step 4: what it really costs (15 minutes)

Owners guess badly about time. Measure one task inside this process instead:

- Task: ________________________________
- Time it 3 to 5 times (start to finish, note interruptions): ______, ______, ______, ______, ______
- Average minutes: ______
- Times per week it happens: ______
- **Weekly hours on this one task: ______**

Multiply weekly hours by what an hour of that person's time costs you. That number is the budget you can justify spending to fix it, every single month.

## Step 5: the one thing (10 minutes)

Look back at your map. You marked a star (longest wait), circles (double data entry), and checkboxes (wastes). They usually point at the same one or two spots.

Write it down:

- The bottleneck: ________________________________
- Why it happens (ask "why" up to five times until you hit a process gap, not a person): ________________________________
- The fix type (circle one): **process change** / **automation** / **delegation**

That is your starting point. Not an AI strategy, not a new platform. One process, one bottleneck, one fix, measured by the weekly-hours number you calculated in step 4.
