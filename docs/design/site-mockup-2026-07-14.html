work / vora
● live · saas platform · voratechnology.com

Vora

A CRM where the AI does the work, not just the note-taking. Built for service businesses that can't afford a front office.

1 / what it is

A platform that answers the phone, follows up with leads, sends the campaigns, and keeps the pipeline honest. Nine industry verticals, from home services to healthcare.

2 / who uses it

Service businesses and the agencies that manage them. Owners who were losing jobs to voicemail.

3 / the AI inside

Voice agents answer calls and book appointments around the clock. Campaign agents write and send email under approval gates. An assistant answers from the org's own knowledge base. Every automated action logs to an audit trail a human can review.

for the technical reader
  • voice: telephony agents with tool access to calendar + CRM state
  • campaigns: LLM generation behind approval workflows, per-org autonomy modes
  • knowledge: retrieval over org documents, answers cite source records
  • MCP server: external agents operate the CRM through typed tools
stack: sveltekit · postgres · docker on hetzner · anthropic + gemini apis · twilio

band A / the stack in practice

A normal working day

Agents write code in parallel

Claude Code is my development environment. For bigger features, a team of agents splits the work: one writes, one reviews, one tests. I direct; they type.

daily

The right model for each task

A router picks the model per request: heavyweight reasoning for architecture, fast models for routine edits. Cost and speed tuned automatically.

automatic

Loops that ship overnight

Autonomous agents on my home server pick up queued tasks, run them, verify the results, and open pull requests. I review over coffee.

while i sleep

Memory across sessions

Decisions, gotchas, and rejected approaches get captured to a knowledge base. New sessions recall past conclusions instead of re-deriving them.

compounding
